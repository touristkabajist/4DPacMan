# 4D Pac-Man

A browser-based 4D maze game built with TypeScript, Vite, and Three.js. The project turns classic Pac-Man gameplay into a four-dimensional navigation puzzle: you move through a 4D space, collect glowing targets, avoid obstacle slices, and finish each level by planning the best route through the extra dimension.

This repository contains the game project under the `4dPacMan/` directory.

## Features

- 4D spatial movement and camera controls
- Multiple handcrafted levels and progression system
- Obstacle-based navigation using 3D cross-sections of 4D shapes
- Visual guide lines and distance indicators for target collection
- Lightweight web build with Vite and TypeScript
- Browser play with no backend required

## Running locally

From the project directory:

```bash
cd 4dPacMan
npm install
npm run dev
```

Then open the local URL reported by Vite in your browser.

Typical local output:

```text
➜  Local:   http://localhost:5173/
➜  Network: http://192.168.4.243:5173/  WLAN
```

This means the game is available locally at `http://localhost:5173/` and also on the LAN at the displayed network address.

## Production build

```bash
cd 4dPacMan
npm run build
```

The build output is generated by Vite and can be previewed with:

```bash
npm run preview
```

## Controls

The game includes keyboard and pointer controls:

- Drag to rotate the camera
- Right-drag or Shift+drag to rotate in 4D
- Mouse wheel to zoom
- Use the visible axis buttons or keyboard shortcuts shown in-game
- Press the level/help buttons from the HUD to open the in-game menu

## Gameplay overview

Each round places you in a 4D grid with glowing target points to collect. The key challenge is recognizing that objects may appear overlapped in 2D/3D projection while actually being separated in the fourth dimension. By rotating the scene and planning movement across the four axes, you can clear the level in as few moves as possible.

## Notes

- The game is a frontend-only project; no server is required for normal play.
- The repo appears to include a macOS metadata folder (`__MACOSX`) that is not part of the game itself.
- The main game code lives under `4dPacMan/src/`.
